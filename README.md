# APOGEE PM Website

Static website prototype for APOGEE PM LLC.

Live site:
https://apogeepmva-jpg.github.io/apogee/

## Deployment

The site is published with GitHub Pages from:

- Branch: `main`
- Folder: `/`

## Local Preview

From this folder:

```bash
python3 -m http.server 4317
```

Then open:

```text
http://localhost:4317/
```
